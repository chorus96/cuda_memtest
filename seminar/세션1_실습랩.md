## 오늘의 주인공 코드

이번 세션의 모든 실습은 `tests.cpp`의 **가장 단순한 커널** 하나를 중심으로 돕니다.

```c
// tests.cpp:245
__global__ void
kernel_move_inv_write(char* _ptr, char* end_ptr, unsigned int pattern)
{
    unsigned int i;
    unsigned int* ptr = (unsigned int*) (_ptr + blockIdx.x*BLOCKSIZE);   // ← 이 블록이 맡을 위치
    if (ptr >= (unsigned int*) end_ptr) {                                // ← 범위 밖이면 아무것도 안 함
        return;
    }

    for (i = 0; i < BLOCKSIZE/sizeof(unsigned int); i++){                // ← 1 MB를 4바이트씩
        ptr[i] = pattern;                                               // ← 패턴을 씀
    }
    return;
}
```

**읽는 법 (강사와 함께 한 줄씩)**
- `__global__` : 이 함수는 **커널(kernel)** — CPU가 호출하고 GPU가 실행합니다.
- `blockIdx.x` : 지금 실행 중인 **블록(block)의 번호**. 블록 0은 첫 1 MB, 블록 1은 다음 1 MB를 담당.
- `BLOCKSIZE` : `1024*1024` = 1 MB (`cuda_memtest.h:91`).
- 이 커널은 `<<<grid, 1>>>`로 호출됩니다 — **블록당 스레드(thread) 1개**. 그래서 `threadIdx`가 안 보입니다.

호출하는 쪽(호스트 함수):

```c
// tests.cpp:312  (move_inv_test 안)
for (i = 0; i < tot_num_blocks; i += GRIDSIZE){
    dim3 grid;
    grid.x = GRIDSIZE;                                                  // GRIDSIZE = 128 (cuda_memtest.h:92)
    SYNC_CUERR_KERNEL(kernel_move_inv_write<<<grid, 1>>>(ptr + i*BLOCKSIZE, end_ptr, p1));
    SHOW_PROGRESS("move_inv_write", i, tot_num_blocks);
}
```

`<<<grid, 1>>>` = **블록 128개 × 스레드 1개**. 한 번에 128 MB를 처리하고, 루프로 전체 메모리를 훑습니다.
