# CUDA 세미나 — `cuda_memtest`로 배우는 실전 GPU 프로그래밍

이 디렉터리는 `cuda_memtest` 저장소의 **실제 소스 코드**를 교재로 삼는 CUDA 입문 세미나 자료 모음입니다.

- **대상**: C 언어는 알지만 CUDA는 처음인 입문자
- **형식**: 다회차 시리즈 (세션 0 ~ 세션 5)
- **표기**: 한글 용어 옆에 원어(영어)를 병기합니다.

## 세션 로드맵

```
세션 0  환경 구축 & 큰 그림                    ✅ 완성  ← 오리엔테이션
세션 1  CUDA 스레드 모델 & 첫 커널              ✅ 완성
세션 2  메모리 모델 & 데이터 이동               ✅ 완성
세션 3  병렬성 설계 & 성능 (Test 10 대역폭)     ✅ 완성
세션 4  원자연산 & 에러 핸들링                  ✅ 완성
세션 5  멀티 GPU · 이식성 · 미니 프로젝트        ✅ 완성  ← 본편(1~5) 완결
```

각 세션은 **[개념 강의(슬라이드)] → [코드 리딩(실제 파일)] → [실습 랩(직접 수정·실행)]** 3단 구성입니다.

## 슬라이드 덱 다시 만들기

```bash
cd slides
npm install pptxgenjs      # 최초 1회
node build_session0.js     # 세션0_환경구축과_큰그림.pptx 생성
node build_session1.js     # 세션1_CUDA_스레드모델과_첫커널.pptx 생성
node build_session2.js     # 세션2_메모리모델과_데이터이동.pptx 생성
node build_session3.js     # 세션3_병렬성설계와_성능.pptx 생성
node build_session4.js     # 세션4_원자연산과_에러핸들링.pptx 생성
node build_session5.js     # 세션5_멀티GPU_이식성_프로젝트.pptx 생성
```

> 슬라이드는 한글 폰트로 **맑은 고딕(Malgun Gothic)** 을, 코드에는 **Courier New** 를 사용합니다.
> PowerPoint(한국어 Office)에서 정상 표시됩니다.
